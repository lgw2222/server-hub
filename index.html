Server Hub

Runs your local server apps on your own PC.

This site isn't an app you use here. It holds the files Server Hub downloads when it installs or updates itself. Server Hub runs on your PC and gives you a dashboard on your phone for starting, stopping and updating your local apps.

Server Hub's own update address

Steps

  1. Download this folder and unzip it somewhere permanent on the PC, like C:\server-hub.
  2. Install Node.js from nodejs.org if you haven't.
  3. Double-click start.bat and leave the window open.
  4. Open the address it prints on your phone.
  5. Paste the address above into the Server Hub section so it can update itself later.

Only point Server Hub at repos you control. It runs whatever code it downloads.
